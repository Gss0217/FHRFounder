# FHRFounder

## Introduction

This repository provides the official PyTorch implementation of the fetal heart rate (FHR) foundation model described in our paper: "FHRFounder: A Fetal Heart Rate Foundation Model Reveals the Predictive Power for Fetal Demographics and Pregnancy Outcomes".

FHRFounder is a deep learning framework for FHR analysis featuring:
- Signal quality enhancement (FSQI + GAN-based inpainting)
- Self-supervised pre-training (SimCLR) on large-scale FHR data
- Fine-tuning for adverse pregnancy outcomes
